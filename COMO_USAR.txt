=============================================================================
                     SOLUÇÃO DE PROBLEMAS
=============================================================================

❌ Erro: Módulo não encontrado
   Solução: Reinstale as dependências
   > .venv\Scripts\python.exe -m pip install -r requirements.txt

❌ Dashboard não abre
   Solução: Abra manualmente no navegador
   http://localhost:8501

❌ Arquivo de dados não encontrado
   Solução: Verifique o caminho no dashboard (campo na barra lateral)
   ou edite em analise_dados.py (linha 238)

❌ Porta 8501 em uso
   Solução: Use porta diferente
   > .venv\Scripts\python.exe -m streamlit run app_streamlit.py --server.port 8502
