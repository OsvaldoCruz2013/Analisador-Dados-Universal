📊 DASHBOARD UNIVERSAL (Recomendado) - Analisa QUALQUER CSV
───────────────────────────────────────────────────────────────────────
   
   Windows: Duplo clique em → run_universal.bat
   Linux/Mac: Terminal → ./run_universal.sh
   
   Abre em: http://localhost:8502
   
   ✓ Faça upload de qualquer arquivo CSV
   ✓ Análises automáticas instantâneas
   ✓ Funciona com vendas, RH, financeiro, etc.


🏦 DASHBOARD BANCÁRIO - Análise específica de dados bancários
───────────────────────────────────────────────────────────────────────
   
   Windows: Duplo clique em → run_dashboard.bat
   Linux/Mac: Terminal → ./run_dashboard.sh
   
   Abre em: http://localhost:8501
   
   ✓ Upload de CSV/Excel com dados bancários
   ✓ Análises especializadas do setor
