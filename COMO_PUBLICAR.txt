5. ⚠️ COPIE O TOKEN GERADO (você só verá uma vez!)

  ⚠️ SOLUÇÃO DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════

ERRO: "remote origin already exists"
   Solução: git remote remove origin
            git remote add origin https://github.com/OsvaldoCruz2013/analisador-dados-universal.git

ERRO: "repository not found"
   Solução: Verifique se criou o repositório no GitHub
            Nome deve ser exatamente: analisador-dados-universal

ERRO: "authentication failed"
   Solução: Use o TOKEN (ghp_xxxxx...) como senha, não a senha da conta

ERRO: "failed to push some refs"
   Solução: git pull origin main --rebase
            git push -u origin main
