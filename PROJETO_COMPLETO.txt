└─────────────────────────────────────────────────────────────────────┘

   1. Acesse: https://share.streamlit.io/
   
   2. Conecte com sua conta GitHub
   
   3. Clique em "New app"
   
   4. Configure:
      • Repository: SEU_REPOSITORIO
      • Branch: main
      • Main file path: 
        
        ESCOLHA:
        → app_universal.py (recomendado - funciona com qualquer CSV) ⭐
        → app_streamlit.py (específico para dados bancários)
   
   5. Clique em "Deploy!"
   
   6. Seu app estará online em:
      https://SEU_APP.streamlit.app

  ⚠️ SOLUÇÃO DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════

PROBLEMA: "Python não encontrado"
   SOLUÇÃO: Execute setup_venv.bat primeiro

PROBLEMA: "Porta já em uso"
   SOLUÇÃO: Feche o dashboard anterior ou use outra porta

PROBLEMA: "Erro ao ler arquivo CSV"
   SOLUÇÃO: O sistema tenta UTF-8 e Latin-1 automaticamente
            Se falhar, salve o CSV como UTF-8 no Excel

PROBLEMA: "Gráfico não aparece"
   SOLUÇÃO: Verifique se há dados suficientes (mínimo 2 registros)
            Verifique valores nulos na coluna

PROBLEMA: "Muitas colunas"
   SOLUÇÃO: Dashboard universal suporta até 1000 colunas
            Análises focam nas 50 primeiras por performance
